I Learning Git with GitHub

**Important ReadMe formats:** <br>
- heading using '#/==' 
- subheading using '--'
- italic using '*'
- bold using '**'
- list using '-'
<br>

**Important Git commands:**
- git init: initialize local repository
- git add [file]: allow files listed (or write . to select all) to be saved / commited
- git commit -m: save changes to the files added earlier with a message
- git checkout: move from commits or branches
- git reset: resets a commit to the commit permanently
- git remote add origin <link>: link the local repo to remote repo
- git revert: revert / move back to the previous commit
- git push origin <branch> : push to a remote github repository from a certain branch
- git pull origin main: copy the main branch of remote repo to local repo
